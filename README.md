# JavaScript Calculator

A simple calculator built with HTML and JavaScript.

## Features

- Performs addition, subtraction, multiplication, and division
- Supports both clickable buttons and keyboard input
- Includes a clear button to reset the calculator
- Prevents division by zero with an error message

## Technologies Used

- HTML
- JavaScript

## What I Learned

This project helped me practice JavaScript functions, event handling, DOM manipulation, loops, and conditional statements.
